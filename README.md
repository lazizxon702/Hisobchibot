# «Ҳисобчи» — Telegram Муддатли Тўлов, Товарлар ва Қарздорликларни Бошқариш Тизими

Ушбу лойиҳа муддатли тўлов (насия/рассрочка) дастурлари, буюртмалар, товарлар ва уларнинг физик бирликлари (IMEI / штрихкод), техника сотуви, тўловлар, аралаш валюталар (UZS / USD), қарздорликлар ва аудит журналини бошқариш учун ишлаб чиқилган тўлиқ функционал backend ва Telegram бот тизими ҳисобланади.

---

## 🚀 Технологиялар стеки

- **Backend Framework**: [NestJS](https://nestjs.com/) (модулли архитектура, TypeScript strict mode).
- **Telegram Bot API**: [grammY](https://grammy.dev/) (update deduplication, dynamic role keyboards).
- **Маълумотлар базаси**: [PostgreSQL 17/18](https://www.postgresql.org/) ва [Prisma ORM](https://www.prisma.io/).
- **Кэш ва қулфлар**: [Redis](https://redis.io/) (тарқатилган қулфлар, идемпотентлик).
- **Файллар омбори**: [MinIO / AWS S3](https://min.io/) (паспортлар, шартномалар ва видео эслатмалар учун ҳимояланган омбор).
- **Ишончлилик**: Transactional Outbox Pattern, Optimistic Concurrency Control (`version`).
- **Тестлар**: [Vitest](https://vitest.dev/) (барча 21 та бизнес сценарийлар бўйича тўлиқ автоматик тестлар).
- **Контейнерлаштириш**: Docker ва Docker Compose.

## 👥 Тизим роллари ва рухсатлар

1. **SUPER_ADMIN**:
   - Барча фойдаланувчиларни тасдиқлайди ва ролларни бошқаради.
   - Барча буюртмалар, сотувлар ва ҳисоботларни кўради.
   - Хато тўловларни сабаби билан бекор қилади (`PaymentReversal`).
   - Аудит журнали ва молиявий тарихга тўлиқ кириш ҳуқуқига эга.
2. **SELLER (1-босқич ходими)**:
   - Янги буюртма очади ва 1–20-бандларни тўлдиради.
   - Шартнома ва паспорт файлларни бириктиради.
   - Лимитларни назорат қилади (ечиладиган лимит <= умумий лимит).
   - Рухсат этилган буюртмани 2-босқич операторига ўтказади.
3. **DAFTAR_REVIEWER**:
   - Дафтар тасдиғини текширади: «Подтверждено», «Надо исправить», «В ожидании», «Не требуется».
   - «Надо исправить» танланганда изоҳ (сабаб) киритиши шарт; сотувчига билдиришнома юборилади.
4. **CONTINUATION_OPERATOR (2-босқич ходими)**:
   - Ўзига бириктирилган буюртмаларни қабул қилади (`IN_PROGRESS`).
   - 21–36-бандларни тўлдиради, жисмоний товарларни сотади (қисман сотув имконияти билан).
   - Тўловларни қабул қилади (Нақд / Банк ўтказмаси, UZS / USD келишилган курс билан).
   - Фақат ўзига бириктирилган буюртмаларнинг «Қарздорликлар» бўлимига кира олади (бошқа оператор буюртмасини ID билан ҳам оча олмайди).

## ⚙️ Локал ва Docker муҳитида ишга тушириш

### 1. Созламалар (.env)
`.env.example` асосида `.env` файлини созланг:
```env
BOT_TOKEN=9167571167:AAG9nOKq8IoKV0h8wfl2xKSeXhoYYiwppz0
SUPER_ADMIN_TELEGRAM_ID=0
DATABASE_URL=postgresql://hisobchi:hisobchi_secret@localhost:5432/hisobchi_db?schema=public
REDIS_URL=redis://localhost:6379
APP_TIMEZONE=Asia/Tashkent
STORAGE_DRIVER=local
LOCAL_STORAGE_DIR=./uploads
```

### 2. Docker Compose орқали ишга тушириш
Барча хизматларни (PostgreSQL, Redis, MinIO ва NestJS App) бир буйруқ билан ишга туширинг:
```bash
docker compose up -d
```

### 3. Локал ишлаб чиқиш муҳитида ишга тушириш
```powershell
# Боғлиқликларни ўрнатиш
npm install

# Prisma миграцияларини қўллаш
npx prisma migrate deploy

# Бошланғич маълумотларни (роллар, дастурлар, дўконлар) базага ёзиш
npm run seed

# Лойиҳани тест қилиш
npm run test

# Лойиҳани қуриш (production build)
npm run build

# Ишга тушириш
npm run start:dev
```
